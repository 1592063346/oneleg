# 万籁阁比赛数据统计

## 使用方式

### 开发模式

适合需要修改 `data.json` 或源码的场景。

```bash
npm install
npm run serve
```

然后通过浏览器访问。

改完代码记得先 `npm run build`。

### 静态网页

`release/` 文件夹包含已编译的静态网页，可以直接打开。

编译得到的方法如下：

```bash
npx tsc && node build.js
```

## 更新数据

### 更新比赛数据

向 `data.json` 中添加新的比赛记录，格式如下：

```json
{
  "date": "2026-08-10",
  "title": "2026.08.10 万籁阁积分赛",
  "type": "积分赛", // "积分赛" | "娱乐赛" | "王中王邀请赛"
  "1st": {"id": "选手名", "deck": "卡组名"},
  "2nd": {"id": "选手名", "deck": "卡组名"},
  "3_4th": [
    {"id": "选手名", "deck": "卡组名"},
    {"id": "选手名", "deck": "卡组名"}
  ],
  "decks": [
    {"name": "卡组名", "num": 数量}, // 可无需按照数量递减
    ...
  ]
}
```

### 添加卡组图片

在 `pic/` 文件夹中添加以卡组名命名的 PNG 图片，有新的上位卡组时需要及时更新这一项，否则饼图中的相应部分会以纯色呈现。
