# 万籁阁比赛数据统计

## 使用方式

```bash
npm install
npm run build
npm run serve
```

然后通过浏览器访问。

改完代码记得先 `npm run build`。

## 更新数据

### 更新比赛数据

向 `data/data.json` 中添加新的比赛记录，格式如下：

```json
{
  "date": "2026/08/10", // 按实际情况写，标题也是
  "title": "2026/08/10 万籁阁积分赛",
  "type": "积分赛", // "积分赛" | "娱乐赛" | "王中王邀请赛" | "特殊规则赛"
  "disc": "一次普普通通的积分赛。", // 比赛描述，可选项
  "env": "ocg", // 比赛环境，可选项，"ocg" | "sc" | "tcg"（默认 "ocg"）
  "1st": {"id": "选手名", "deck": "卡组名", "deck_file": true},
  // 冠军是必填项，亚军和四强是可选项
  // 选手名和卡组名可用字符串 [TBD] 充当临时占位符
  // 对于单个选手：构筑文件 deck_file 是可选项，如果为 true，则需要在 data/deck/ 文件夹中添加相应的构筑 ydk 文件，
  // 命名为 [当前比赛日期]_[选手名].ydk
  "2nd": {"id": "选手名", "deck": "卡组名"},
  "3_4th": [
    {"id": "选手名", "deck": "卡组名"},
    {"id": "选手名", "deck": "卡组名"}
  ],
  "decks": [
    // 统计环境卡组及其数量，卡组可无需按照数量递减排列
    {"name": "卡组名A", "num": 3},
    {"name": "卡组名B", "num": 5, "archetypes": [{"name": "子字段名", "num": 2}, ...]},
    // 对于每个卡组：子字段 archetypes 是一个可选项，用于描述该卡组里面外挂的字段以及相应的卡组数量
    // 一个带有子字段的卡组的例子是：
    // {"name": "光与暗的仪式", "num": 5, "archetypes": [{"name": "烙印", "num": 2}, {"name": "黑魔导", "num": 1}]}
    ...
  ],
  "deck_num": 30 // 可选项，一般是根据上面的 decks 直接计算，但是有时候环境可能没有统计，便需要一个参赛人数的裸数据
}
```

### 更新国内大赛数据

向 `data/event_data.json` 中添加新的比赛记录，格式整体上与上面一致，不过要注意：

1. 比赛类型（`type`）：“城市巡回赛”、“YCS”、“特别大会”、“WCQ 预选赛”、“WCQ”。
2. 选手构筑放置文件夹为 `data/event_deck/`。
3. 新增字段 `elimination_decks`，表示淘汰赛卡组列表，格式与 `decks` 相同。
4. 环境数据可能需要自己做一些处理……

### 添加卡组图片

有新的上位卡组时需要及时更新这一项，否则饼图中的相应部分会以纯色呈现。

在 `sources/pic/` 文件夹中添加以卡组名命名的 webp 图片，此外还需要在 `sources/pic/center.json` 中添加图片的尺寸（`size`）以及焦点选取（`center`，两个数字分别表示距离图片左上角的横向像素距离与纵向像素距离）。

注意：图片应尽量接近正方形，压缩到 40~50KB 为宜。

### 添加禁卡表

禁卡表主要是服务于“构筑导出”功能的。

有新的禁卡表时，需要在 `data/limits/` 里添加新的 json 文件，并把文件名添加到 `data/limits/index.json` 里。文件格式如下：

```json
{
  "name": "2026 年 7 月禁限卡表（OCG）", // 禁卡表名称
  "tag": "202607_ocg", // 禁卡表唯一英文标识符，遵照此格式：YYYYMM_[ocg/sc]
  "all": {
    // 禁限制卡的卡密以及其对应的限制张数（0/1/2 分别对应禁止/限制/准限制），顺序无所谓
    "89392810": 0,
    "16387555": 1,
    "92248362": 2,
    ...
  }
}
```

从维护角度出发，每次出新的禁卡表时，只需要复制一份上一次禁卡表的 json 文件，然后照着有改动的卡片条目修改后面的数字或者直接增删条目，即可做出新表对应的 json 文件。
